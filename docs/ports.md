# Using agent-skills from GitHub Copilot and OpenAI Codex

`agent-skills` is written for Claude Code. `scripts/port.py` generates equivalent copies for GitHub Copilot CLI and OpenAI Codex under `ports/` (ADR 0015). The mods (`tool-fold`, `plan-progress`) are Claude-only and are not listed for other tools. What each tool supports of the Claude Code plugin surface, including hooks and Google's Antigravity CLI, is in [platform-parity.md](platform-parity.md).

> Generated files: never edit `ports/`, `.github/plugin/marketplace.json`, `.agents/plugins/marketplace.json` or `user-config/{offload-policy,routing}.{copilot,codex}.md` or the README block between the `recommended-prompt` markers by hand. Change the Claude source, then run `python3 scripts/port.py`; `scripts/validate.py` fails while they are stale.

## Install

Install steps for Copilot CLI and Codex are in the [README](../README.md#install); the recommended prompt (offload table and routing) is in [its section](../README.md#recommended-prompt).

## What maps to what

| Claude Code | Copilot CLI | Codex |
|---|---|---|
| Skill | Same skill; paths point to the installed copy | Same skill (`agent-skills:<skill>`); paths point to the installed copy |
| Command `/agent-skills:<cmd>` | Skill `/<cmd>`, user-only (`disable-model-invocation`) | Skill `agent-skills:<cmd>`, implicit invocation off (`agents/openai.yaml`) |
| Agent | `.agent.md`: same text, same Claude model and effort, tool allowlist | Role file: same text, nearest GPT model, same effort |
| `skills:` preload | Skill text appended to the agent | Same |
| `tools` / `disallowedTools` | Enforced by `tools` | Stated as rules. `shell_tool = false` would enforce "no shell", but Codex also reads files through its shell, so it applies only to an agent without Bash, Read, Grep and Glob (none today) |
| `omitClaudeMd` | `include-custom-instructions` | No equivalent |
| `maxTurns` | Stated as a rule | Stated as a rule |
| Claude-only names in the text (`Explore`, `AskUserQuestion`, "CLAUDE.md" for delegation rules) | Mapped to Copilot's equivalents; `/agent-skills:<x>` becomes `/<x>` | Mapped to Codex's; model tags such as "(Haiku)" become the GPT model |
| Mods, evals | — | — |

`python3 scripts/port.py --report` prints the full mapping; `--check` proves it, file by file.

## Models

Copilot runs the same Claude models: model and effort pass through, and the Copilot ids come from the catalog (GitHub's docs give Fable only as a display name, so `claude-fable-5.2` is unconfirmed). Codex maps the (model, effort) pair together. Both come from [`shared/models.toml`](../shared/models.toml), the home of model facts (levels, relative costs, effort policy, pins), so the tables below are generated by `python3 scripts/port.py` and verified by `port.py --check`; edit the catalog, not the tables.

**Semantics.** Each Claude pair maps to the allowed Codex pair with the smallest capability grade (`level` plus a step per effort) that matches or beats it, ties to the cheaper; a pair above every allowed target maps to the highest allowed one. Effort policy: `max` is never chosen as a target, and `xhigh` only on the vendor's top model. The two vendors' plans have different budgets, so cost is compared only within a vendor: each scale is relative to the cheapest model of its own vendor. Levels are owner judgments on a scale shared across vendors, fitted so that every cell an agent uses keeps its pair. Pins (`[[overrides]]` in the catalog, each with its owner ruling as `reason`) replace the derived pair of one cell; a pin with a forbidden effort or an unknown model fails to load. Agents use only `low`, `medium` and `high` (`AGENT_EFFORTS` in `scripts/validate.py`); the `xhigh` and `max` rows are kept current for when that set widens. `scripts/tests/test_models.py` pins the Codex pair of every cell an agent uses, so a catalog edit that moves one fails until that test is updated on purpose.

**Sources.** Codex cost: plan credits per token (`learn.chatgpt.com/docs/pricing`, 2026-11-19; `gpt-6.1-sol` costs the same as `gpt-6.2-sol`). Claude cost: API list price per token (Haiku 5.5 $0.10/$0.50 per 1M up to 100K-token prompts, Sonnet $2/$10, Opus $4/$20, Fable $8/$40; Anthropic pricing, 2026-11). Effort does not change the price per token, only how many tokens a task uses. Each tier uses its newest listed version; terra has no 6.2 release, so it stays on `gpt-6.1-terra`. Models as of 2026-11-19 (`codex-rs/models-manager/models.json`); change `shared/models.toml` when the tools' model lists change. The switch to the derived table and its effect: ADR 0029. A pair missing from the table fails `port.py --check`. Copilot falls back to the session model when a listed model is unavailable.

## Limits

- Unmeasured: neither tool has an eval command, and the descriptions and delegation rules were tuned on Claude.
- Paths assume the default install folders; with a custom `COPILOT_HOME` or `CODEX_HOME` the generated commands use that variable.
- Verified from Copilot's docs source and Codex's source code on 2026-10-30, not by running either tool.
