# Heuristics

## Nielsen's 10 usability heuristics

| # | Heuristic | Check |
|---|---|---|
| H1 | Visibility of system status | Loading, progress, saved/failed states visible and timely |
| H2 | Match with the real world | User vocabulary, natural order, familiar icons |
| H3 | User control and freedom | Undo, cancel, back, exit from flows |
| H4 | Consistency and standards | Same action = same look/word; platform conventions |
| H5 | Error prevention | Constraints, confirmations for destructive acts, sensible defaults |
| H6 | Recognition over recall | Options visible; no memorizing across screens |
| H7 | Flexibility and efficiency | Shortcuts, bulk actions, remembered choices for experts |
| H8 | Aesthetic and minimalist design | Every element supports the task; no noise |
| H9 | Help users recover from errors | Plain message, cause, fix; input preserved |
| H10 | Help and documentation | Contextual help where tasks are complex |

## Nielsen severity scale

| 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Not a problem | Cosmetic | Minor (low priority) | Major (high priority) | Catastrophe (fix before release) |

Severity = frequency × impact × persistence.

## Shneiderman's 8 golden rules

Consistency · Universal usability · Informative feedback · Dialogs yield closure · Prevent errors · Easy reversal · User in control · Reduce short-term memory load.

## Norman, *The Design of Everyday Things*

| Concept | Meaning |
|---|---|
| Affordance | What an object allows |
| Signifier | What tells the user it is possible (button looks pressable) |
| Mapping | Control layout matches effect |
| Feedback | Immediate, informative result of action |
| Constraints | Physical/logical limits that prevent errors |
| Conceptual model | User's mental model matches system model |
| Gulfs of execution/evaluation | "How do I do it?" / "Did it work?" |

## Forms checklist

Labels always visible (no placeholder-only) · one column · group related fields · mark optional, not required (or both consistently) · inline validation on blur, not on every keystroke · correct `type`/`inputmode`/`autocomplete` · primary action obvious, destructive action separated.
