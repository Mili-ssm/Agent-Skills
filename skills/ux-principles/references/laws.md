# Laws of UX and Gestalt

## Laws (lawsofux.com selection)

| Law | Statement | Design implication |
|---|---|---|
| Fitts | Time to target ∝ distance / size | Big, close targets for frequent actions; edges/corners are fast |
| Hick–Hyman | Decision time grows with number of choices | Fewer options; progressive disclosure; sensible defaults |
| Jakob | Users expect your site to work like others | Follow conventions before inventing |
| Miller | ~7±2 items in working memory (chunking matters more than the number) | Chunk information; don't rely on memory |
| Doherty threshold | Productivity soars when response < ~400 ms | Optimistic UI, indicators, fast partial updates |
| Tesler (conservation of complexity) | Complexity can't vanish, only move | Move it to the system, not the user |
| Postel (UX) | Liberal in input accepted | Accept formats (phone, dates); normalize server-side |
| Peak–end rule | Experiences judged by peak and end | Polish success states and completion |
| Serial position | First and last items remembered best | Key nav items at ends |
| Von Restorff (isolation) | The distinct item is remembered | One visually distinct primary action |
| Zeigarnik | Incomplete tasks are remembered | Progress indicators, resumable flows |
| Goal-gradient | Effort increases near the goal | Show progress; shorten perceived distance |
| Aesthetic–usability | Attractive designs perceived as easier | Polish matters, but never over function |
| Parkinson | Task expands to fill time | Autofill, smart defaults |
| Choice overload | Too many options → paralysis | Curate, compare tables, recommend |
| Cognitive load | Mental resources are limited | Remove extraneous load |

## Gestalt principles

| Principle | Use |
|---|---|
| Proximity | Related items close; spacing defines groups more than borders |
| Similarity | Same style = same function |
| Common region | Cards/containers group content |
| Continuity | Aligned items read as a sequence |
| Closure | Users complete partial shapes; minimal icons work |
| Figure–ground | Clear foreground (modals, focus) vs. background |
| Uniform connectedness | Lines/connectors group strongest |
| Prägnanz | Simplest interpretation wins; simplify shapes and layouts |

## Interaction timing (Nielsen / Card et al.)

| Delay | Perception | Response |
|---|---|---|
| < 100 ms | Instant | No indicator |
| 100 ms – 1 s | Noticeable, flow kept | Subtle indicator optional |
| 1 – 10 s | Attention drifts | Spinner/skeleton |
| > 10 s | Task switch | Progress bar + cancel + notify on completion |
